# ZeronKit Portfolio

A free WordPress plugin that adds what a photographer or small studio needs: portfolio projects, services with prices, client quotes and a booking form that saves every message.

It is made for the [ZeronKit themes](https://github.com/zeronkit/zeronkit-themes), which show everything as soon as the plugin is active, and it works on its own with any theme.

## Features

- **Projects:** a portfolio with a gallery per project, location, date, client, categories, types and places, filters without a page reload and an accessible lightbox.
- **Services:** price, duration and what is included. The contact form offers them as choices.
- **Kind words:** client quotes and press mentions.
- **Inquiries:** a contact and booking form with spam protection. Every message is saved in the dashboard before the email is sent, so nothing is lost if email fails.
- **Site details:** one settings page for the tagline, introduction, contact details, social links and the optional booking button and banner.
- **Search tags:** meta description, Open Graph and basic structured data, switched off by itself when a major SEO plugin is active.

No remote requests, no tracking, no files from other servers.

## Install

1. Download this repository as a zip, or clone it into `wp-content/plugins/zeronkit-portfolio`.
2. Activate **ZeronKit Portfolio** in WordPress.
3. Fill in **Settings > ZeronKit Portfolio**.

Sample content for a fresh site: `wp zeronkit-portfolio seed`

Requires WordPress 6.5 or newer and PHP 8.1 or newer.
